# Phone pass

Run on a dev build before each OTA. Run only the flows your change touches.

## Did you link (two accounts)
1. Send a Did you link from account A.
2. Preview text reads as a full question (`didYouAsk`) with a full https link.
3. Open on account B. Keep it. Lands on Tonight.
4. Account A gets the push.

## Did we link
1. Share a Did we. Join on a second account.
2. It shows on Tonight for both.
3. Widget shows it once it has a matching item.

## Remove a friend
1. Remove a friend who shares a Did we.
2. You get the keep or leave choice for the shared Did we.
3. Open their page after. It shows not friends, no stale data.

## Leave a family
1. Leave. Family questions and Tonight update.
2. Links you made stop working.

## Widget
1. Finish your own questions with a Did we still open.
2. Widget shows the Did we, not "all clear".
3. Tap Did on the widget. App and widget agree.

## Toasts
1. Run one action per area (friends, family, shop, links).
2. Each shows one message. Never blank, never twice.

## Sign out / in
1. Sign out. Tonight and widget clear.
2. Sign back in. Questions, streaks, and coins come back.

## Shop buy
1. Buy a look. The confirm sheet shows (SheetHost).
2. Coins or gems drop once. The look applies.
