Opening ideas · first time someone opens Did I

Make the first two seconds count

Four ways in. The phone's splash itself has to be still (it shows before the app has loaded), so each of these plays as the first screen right after it, starting from a matching picture so it feels like one piece. Each ends on the sign-in screen, which is what a first-time user sees. Tap anyone to skip.

My pick: 1 or 2 the first time, and a short 4 on later opens so returning people are not slowed down. Reduced motion gets a plain fade. Timings here are close to what they would be in the app (1.5 to 3 seconds).
