The other options

For comparison. Each works; each has a catch.

SQUIRRELForgets where the nuts areThe ADHD crowd already jokes "squirrel!". Very relatable, but it says "distracted" more than "did I?", and some find the joke tired.
GOLDFISHThe three-second memoryFunny and gentle, great in short videos. The catch: it laughs at the user's memory, which can read as a dig.
ELEPHANTNever forgets, so you don't have toFlips it: the app remembers for you. The catch: elephants are common in memory and note apps, so it's less yours.
